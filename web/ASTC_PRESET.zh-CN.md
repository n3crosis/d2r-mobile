# ASTC 预设选择

English: [ASTC_PRESET.md](ASTC_PRESET.md)

浏览器界面仅在启用实验性旧 GPU 选项时显示小型编码预设选择器。默认使用精细。
快速模式以可能较低的图像质量换取较短处理时间，不承诺数字化加速或设备兼容性。

只有 `astcPreset=fast` 选择快速。缺失或未知 URL 值回退精细；选择精细会删除
该查询参数。与实验性选项一样，更改预设会在选择私有输入前重新加载页面，并把
固定值传给浏览器打包器设置。选过文件夹、处理/生成期间或已有输出时，选择器
被锁定。关闭实验性选项会隐藏选择器，不会在正常模式启用 ASTC 处理。

所有标签和说明来自 `dm/i18n/ui_text.tsv`，浏览器与原生目录均由此生成。
界面源码溯源哈希随该表更新；annotation-data 载荷保持不变。此 UI 不扩大后端
封闭预设验证，也不改变转换、载荷、工作线程或导出逻辑。

范围内检查包括目录/头文件一致性、文字规范、已有旧 GPU 和资源选项源码契约、
选择器 URL/默认/锁定断言、TypeScript 和格式/lint。它们不代替浏览器交互、
质量对比或设备测试。
