# Bounded logical-asset suffix batches

[简体中文](LOGICAL_ASSET_SUFFIX_BATCH.zh-CN.md)

The authenticated extraction adapter offers `findUniquePathSuffixes(suffixes)` alongside the unchanged singular API. Shader generation resolves its distinct external pack names in native processing order; remaining and mercenary art resolve their known sprite queries in existing read order. Reads, output ordering and authenticated capabilities are unchanged. Singular-only test adapters remain supported through `resolveLogicalAssetSuffixes`.

A batch accepts at most 4,096 requests and 1 MiB of ASCII suffix bytes, including repeated requests. Each suffix retains the existing 512-character lowercase safe-path rule. Invalid requests or budgets reject before scanning. Empty batches perform no scan but still check cancellation/session lifetime.

Requested suffixes are grouped by basename. One manifest pass lowercases each visited path once and compares only suffixes in its basename group. The helper retains original matching rows and ambiguity flags, not a second full-catalog index, normalized path list, archive bytes or decoded assets. Duplicate requested suffixes share matching work but return their original request positions. Same-basename collisions still require full `endsWith` comparison; normalized duplicate manifest paths remain ambiguous. Missing/ambiguity outcomes are resolved in request order after the scan, matching independent singular lookups for valid requests. Cancellation is checked per scanned row and during request/result processing. Each call scans afresh; nothing persists between calls.

A synthetic 200,000-row catalog with 64 distinct-basename requests measures 12,800,000 path-lowercase calls and suffix comparisons for independent scans, versus 200,000 lowercase calls and 64 suffix comparisons for the batch, with identical ordered results. The counter fixture isolates path scanning; real matched-path duplicate validation can perform additional normalization. Basename-heavy collisions can still require up to `rows × requests` suffix comparisons within the bounded request set. These are operation counts, not real-browser timing, heap measurements or game/device validation.
