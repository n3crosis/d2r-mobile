# 有界纹理容器流式适配器

[English](TEXTURE_STREAM.md)

仅为隔离源码，未接入生产。`texture-stream.mjs` 按 `dm/tools/astc_pack.py` 的结构解释包装 `bc3-astc-batches.mjs`：格式字节位于偏移 4，无符号小端相对数据指针位于偏移 40，`dataStart = 40 + pointer`。BC3 格式 0x3d 映射为 ASTC 0x5f，采用线性编码；0x3e 映射为 0x51，采用 sRGB 编码。其余头部字节逐字节保留。负载仍为每块 16 字节，因此输出文件长度和偏移不变。

## 流契约

`transcodeTextureStream(source, { signal, batchBlocks, encode })` 消费具有非负安全整数 `size` 的 readAt 来源。`readAt(offset, length, { signal })` 必须返回长度准确、固定、非共享的 Uint8Array。它产出分类事件：

- `skip`：少于 48 字节时原因为 `short-input`；不支持的格式为 `unsupported-format`，附带观察到的数字格式码。这些情况不产出字节或完成事件。跳过是明确的，不会静默重写不支持的文件。
- `header`：独占字节块与绝对输出偏移。首个事件还报告原格式、新格式、dataStart 与配置。仅修改字节 4。首读为 48 字节，随后头部块最多 64 KiB。即使头部异常长，也流式处理而不完整保留。
- `blocks`：原始 ASTC 字节块、绝对输出偏移、块数、已完成块数与总块数。使用现有顺序有界批处理适配器，每块数据最多 1 MiB。编码配置由原格式决定，不猜测，也不让调用者覆盖。
- `complete`：仅在全部头部与负载字节成功产出后发出，包含不变的文件大小与格式、配置。它不代表下游文件写入器已持久化输出。

消费者必须区分事件类别、及时消费字节块，并明确处理跳过。适配器不写入，不保留完整纹理或 CASC 包。错误、取消或提前终止后的部分输出清理由消费者负责。保留全部产出块会主动失去流式优势。头部块复制后输出，避免保留巨大的来源底层缓冲区；来源缓存与 JavaScript 垃圾回收不受适配器控制。

## 边界、取消与原生差异

支持的格式必须满足：数据起点至少为 48、严格小于来源大小，且剩余非空尾部可被 16 整除。拒绝 dataStart 小于 48 是有意加强的畸形输入验证；原生脚本未显式拒绝与头部重叠。格式映射、指针解释、未修改头部字节与块顺序遵循原生结构规则，但不证明完整原生转换对等。

在首个输出前检查可预见的批处理选项错误。短读、错误缓冲区类型、共享或可变长缓冲区、不安全大小和畸形偏移均失败。调用者读取函数或注入编码器的错误替换为固定类别信息，不包含私有文件名或原始原因。取消错误保留通用 AbortError 类别。

取消信号传入头部读取与批处理适配器，在块间检查，也停止等待未完成读取。底层读取仅在来源遵守信号时释放资源。同步有界解码不协作式中途打断。在产出块处跳出可阻止后续读取；中断已进行工作需要 AbortSignal。流未完成时，之前的字节块不构成完整有效转换。

这里不实现 mip 表解析、纹理尺寸解释、描述缓存更新、缩略图变化、CASC 写入、质量报告或游戏内容处理。原生脚本中独立的容器与包职责仍待完成。

## 合成证据

`node --test texture-stream.test.mjs` 的五个确定性测试通过，使用注入模拟编码器而非真实 ASTC 压缩。用例覆盖两种格式与配置映射、准确头部保留、顺序批次偏移和计数、有界长头部读取、惰性提前停止、显式跳过、重叠或超界或未对齐指针、短读、无效大小与选项、待完成读取取消及保护隐私的错误类别。不宣称真实 WASM 转码、游戏文件行为或完整原生管线对等。
