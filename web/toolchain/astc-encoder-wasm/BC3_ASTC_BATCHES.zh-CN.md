# 有界 BC3 到 ASTC 批处理编排

[English](BC3_ASTC_BATCHES.md)

隔离、未集成的源码基元。它组合已有的有界 BC3 解码器与 ASTC 工作线程客户端；真实浏览器 WASM 转码仍未验证。测试明确注入模拟编码器，不是 Arm ASTC 编码。不涉及生产 UI、CI、游戏文件、纹理元数据重写或补充包写入。

## 契约

`transcodeBC3Batches(source, { profile, signal, batchBlocks = 65536, encode })` 是惰性异步生成器。`source.size` 必须是非负安全整数且为 16 的倍数。零字节不产出结果。`source.readAt(offset, length, { signal })` 必须返回或异步解析为长度准确、固定、非共享的 Uint8Array 视图。短读或超长读取均失败；生成器不重试，也不静默截断。配置必须明确为 `linear` 或 `srgb`。`encode` 默认为 `encodeAstc4x4`；覆盖它仅是依赖注入入口，不代表另一个已验证的编码器。

每个产出项包含 `blocks`（原始 ASTC 块的 Uint8Array）、`blockOffset`、`blockCount`、`completedBlocks`、`totalBlocks` 与 `profile`。偏移和计数以块为单位，而非字节。完成计数在编码成功后增长，仅在生成器完整消费并成功时达到总数。计数是供调用者使用的进度信息，不是持久化事务记录。

一次仅等待一个读取与一个编码。只有消费者请求下一项才读取下一批；没有预取队列。批量为 1–65,536 块，压缩输入与产出 ASTC 均最多 1 MiB。解码器默认每行 1024 块，含末行填充的 RGBA 最多 4 MiB。裁剪前验证带填充 ASTC 长度。只移除尾部零网格填充；不重排或裁掉真实源块。读取字节偏移严格递增。

消费者应写入或消费每个产出块并释放后再前进；收集全部块会主动保留整个输出，失去流式优势。此模块不保留完整纹理或补充包，不写入输出，也不在后续批次失败时回滚。部分输出清理由调用者负责。RGBA 转移到真实工作线程会消耗该中间缓冲区；源输入不被分离或修改。最后一个不完整网格可能短暂同时保留带填充编码输出与紧凑前缀副本。浏览器或模块开销、来源缓存与延迟垃圾回收另占内存，不包含在缓冲区上限内。

## 取消与限制

在开始工作、读取后与编码后检查 AbortSignal，并将其传入来源与编码器。即使注入的操作忽略信号，对读取或编码的等待也可取消，但底层来源仅在遵守信号时才能释放自己的待完成 I/O 资源。真实编码器客户端会终止可丢弃工作线程。自定义编码器若忽略取消，生成器不能强制停止它。同步解码虽有界，但不在函数中途协作式中断。在产出结果处暂停时调用 `return()` 或跳出迭代会阻止后续读取；取消已进行的操作应使用信号。

调用者取消或提前停止时，不得将之前的块视为完整纹理。此模块不解释纹理尺寸、mip 边界、块线性平铺、描述缓存、缩略图或 CASC 布局。它不是完整原生 `astc_pack.py` 流程；BC3 解码源码对等不证明真实 BC3 到 ASTC 转码对等。

## 验证

`node --test bc3-astc-batches.test.mjs` 的四个确定性模拟编码器测试通过。覆盖惰性顺序处理、65,536 块加三块填充尾批、有界输出、单调计数、准确裁剪尾部、畸形长度与配置、短读、错误编码长度、空输入、读取和编码前后及过程中的取消、消费者停止，以及三批间已解码源块身份的保留。真实 WASM 编译、浏览器执行、编码质量与原生及浏览器块对等仍待验证。
