# 有界纹理描述缓存转换

`descriptor-cache.mjs` 依据 `dm/tools/astc_pack.py:desc_cache`，不读取文件或创建补充包。
调用 `transformTextureDescriptorCache(bytes, converted, { signal, batchBlocks, encode })`；
`converted` 是小写 ASCII 逻辑名称到布尔 sRGB 标志的 Map。调用方必须确保这个表
描述实际已转换的纹理；它不是认证或所有权声明。结果只包含 `bytes`、
`convertedEntries` 与 `thumbnailCount`。

选中条目的格式61变为95，62变为81。格式62必须与所选 sRGB 标志一致。
其他格式与未选条目保持不变。缺失、null 和空缩略图保留原形。
JSON 元数据按语义保留，不保留原始空白或数字拼写。

缩略图按原生的小端相对地址读取：偏移0是 u32 数量；表位于4加偏移4的
有符号 i32；每行包含 u32 大小，以及以指针字段自身为起点的有符号相对指针。
所有载荷范围必须位于完整表之后且在缩略图之内，长度须为非零的16字节倍数。
转换顺序由表顺序决定，不由物理范围顺序决定。文件头、表、空隙、尾部以及
所有其他非载荷字节逐字节保持原样，不改写指针。

第一次编码调用之前检查所有选中的元数据与布局。随后至多保留一张解码后的
缩略图，对每级串行调用现有 `transcodeBC3Batches`。有界来源是该缩略图的视图，
不是整包缓冲区。不修改输入描述字节。失败或取消后不返回部分 JSON 输出。
错误只含固定代码（`ASTC_DESCRIPTOR_INVALID`、`ASTC_DESCRIPTOR_TRANSCODE`）
或固定 AbortError，不包含文件名、解析器详情或注入编码器的文本。
底层编码器仍负责取消与释放自己的资源。

## 有意收窄的接受范围

- UTF-8 JSON 数组，输入最多16MiB，输出32MiB，条目与映射键各最多100,000个。
- 每张缩略图最多4MiB，1–64个非空 mip，载荷范围不重叠。
- 表从字节8或以后开始；有符号指针不能到达元数据或超出缩略图。
  支持空隙与逆向物理顺序。
- 只接受规范填充的 base64，不接受空白或不同的填充位。
- Map 键为1–1024字符的小写可打印 ASCII；记录文件名为最多1024字符的字符串。
  匹配前将记录名称转为小写。
- 元数据遍历最多500,000节点及64层。拒绝非有限数及超出 JavaScript 安全范围的
  整数，而不是在序列化时损坏元数据。缩略图字段只允许字符串、null 或缺失。
- 批量限制沿用 `transcodeBC3Batches`（最多65,536块）。

原生先按 sRGB 合并所有缩略图再编码。本实现为控制内存而串行处理 mip 与条目。
已覆盖描述布局及保留行为，但不声称改变分组后生成的 ASTC 字节与原生相同。
真实编码器、完整缓存、图像保真度、完整补充包、设备及游戏行为的一致性尚未证明。
未启用运行时、界面或 CI 集成。

## 定向验证

`node --test web/toolchain/astc-encoder-wasm/descriptor-cache.test.mjs`
只使用手写 JSON、缩略图与注入的模拟编码器。覆盖格式映射、sRGB 不匹配、
串行调用、元数据保留、相对指针/计数/大小/重叠拒绝、逆向物理 mip 顺序、
非载荷字节不变、输入不变、base64/预算失败、错误清理以及挂起编码器的取消。
夹具不包含游戏文件或游戏文件名。
