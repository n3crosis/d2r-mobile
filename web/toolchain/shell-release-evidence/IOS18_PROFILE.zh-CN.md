## 编译后的容量

`v1.0.18-ios18-derived-capacities.json` 将证据绑定到老接口宿主的可执行文件摘要，
记录符号及函数摘要、准确指令与控制流程。使用已安装的 Capstone 5.0.6
解码公开宿主字节，没有执行二进制。计数不是根据数组间距或源模板替换值推断的。

- EXP：100 个标量。文件偏移 0x6f948 的比较、条件选择与相等分支限制索引写入。
  原生函数没有最终精确计数检查；浏览器必须保留生成计数的精确检查。
- VTPART：0xd7e10 的保护拒绝大于 10 的索引；0xd7bc8 的完成检查比较计数 11。
- VTROW：0xd7e4c 的保护拒绝大于 561 的索引；0xd7bd0 的完成检查比较 562。
- VTSET：0xd7f44 的保护拒绝大于 34 的索引；0xd7bd8 的完成检查比较 35。
- TAROW：0x1ca60 的保护在三个字段写入前拒绝大于 428 的索引；0x1cabc
  的完成检查比较 429，并处理缺行和不相等的情形。

## 内容绑定与 Guest 目标

文件支持的 `__DATA,__data` 中唯一的非调试 `_aoc_owned.v` 定义位于
地址 0x10018ede8、文件偏移 0x18ede8，初值为 ffffffff。注册表独立于缺省
外壳记录原始摘要及四字节置零后的摘要。派生过程验证整文件身份、唯一符号与节、
准确偏移和初值，以及完整结果摘要。它使已有签名失效，不证明无扩展模式的可玩性。

Guest 包装格式明确区分最低系统与 SDK 元数据。老接口最低版本 18.0.0 使用
SDK 字段 26.0.0，保留现有手写格式的 SDK 声明契约，而非声称经过苹果 SDK
构建。这与宿主观测到的 SDK 26.5.0 不同。包装器不生成苹果 API 胶水代码，
只声明 libSystem；传入指令与宿主加载仍须单独验收。不可降低未知二进制的
最低版本，或放宽其摘要检查。

既有的源码与构建溯源缺口、完整着色器摘要检查，以及私有输入与设备验收边界
保持不变。这些记录不包含游戏数据、私钥、外壳压缩包或可执行文件。

## 候选集成状态

加载器、内容模式派生、Guest 写入器及生成输出检查一致接收封闭配置身份。
缺省 Guest 可执行文件和 plist 字节仍与原生 Python 自造样本一致。检查覆盖
SDK、最低目标、精确的标准 plist 及无歧义的 Mach-O 命令布局。
针对性合成检查通过。另以固定摘要的公开 iOS 18 可执行文件，在内存中派生
两种内容模式，完整输出摘要均匹配；该检查没有执行二进制或使用游戏输入。

候选界面在选择私有输入之前选定封闭目标，并通过重载切换运行时。
组装包括两份公开外壳；浏览器验证完整清单后，只下载选定外壳及所有通用资产。
此选择功能已通过 CI，并于 2026-10-20 随源码 f4f3326 部署。
此系统配置不实现独立的旧 GPU ASTC 纹理管线。

另使用仓库元数据实际加载公开的旧接口压缩包：全部 16 个清单条目、
13 个文件流、摘要、配方、着色器目录及美术/HUD 固定摘要均通过。
关闭会清零压缩包，后续条目读取被拒绝。这仍是打包证据，不是二进制执行或设备证明。
