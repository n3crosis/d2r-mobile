# 可选生产 ASTC 清单绑定

[English](PRODUCTION_ASTC_BINDING.md)

此接线不改变界面开关、默认 BC 文件、外壳配置选择或运行时载荷选择。引导仍从原有生产外壳契约开始。不接受外部补充包字节、索引 TSV、认证标志或任意额外路径列表。

## 生成器边界

资源生成成功后，可信适配器可以提供同步的 `getAstcOutputBinding()`：

- 未启用、生成前、失败或释放后：`undefined`。
- 启用：`{ pack: { name, size, sha256 }, overlayArchives: { base, item_notes } }`，两个归档值均为从生成结果得到的规范文件名，不含目录。

Getter 仅包含元数据，不复制文件，也不携带记录或外部暂存包。生成器与适配器必须接入真实内部生产器后，此路径才能使用。该边界本身不创建或认证生产器，也不开放面向用户的 ASTC 选项。

## 生成后的精确契约

`selectProductionAstcEntries` 选择以 `romfs_overlay_astc` 开头的路径进行严格检查。在普通过滤器静默丢弃它们之前，拒绝未绑定 ASTC、启用但不完整的集合、外部补充包归档名、根部 `data/*.data`、任意深度的 `pack_index.tsv` 以及 `Legacy Device Pack` 路径。

`inspectProductionAstcEntries` 按[ASTC 输出验证](ASTC_OUTPUT_EXPORT.zh-CN.md)契约检查恰好十一个条目。检查路径唯一、普通 0644 文件模式、安全的声明长度、单文件 64 MiB/总计 128 MiB 上限，以及完整流的实际长度。每个返回缓冲区必须为普通、不可调整大小且最多 1 MiB。迟到的生产器错误和取消都会拒绝输出。

验证器耗尽不透明文件流，但不重建文件。仅保留最多 512 字节的 pack JSON、特性标记的前十一字节，以及其他文件各一字节；声明和实际总长度单独验证。这些小前缀恰好覆盖现有验证器的内容条件，不替代哈希或 CASC 语义验证。不修改调用者拥有的块；检查结束后清零临时前缀。

`bindProductionAstcEntries` 返回替代配置，将验证后的十一个精确文件名加入 `extraFiles`。它重新校验外壳契约，保留原有必需路径、外壳清单、可执行目标及生命周期方法。不修改原配置，不允许目录通配符；重复绑定会被拒绝。

打包器在资源生成之后、外壳加载与组装之前绑定配置。普通 BC 过滤行为保持不变，只额外保留已绑定的精确 ASTC 路径。最终生成输出验证在组装前再次耗尽 ASTC 条目流，核对冻结的 pack/归档绑定。外部补充包数据及索引不会成为 IPA 条目。

## 限制与证据

Getter、暂存包哈希与归档位置分配是内部可信契约，不是用户认证。该层不能证明路径到 CFT 的关联、纹理转换完整性、源补充包完整性或原生设备兼容性。独立补充包导出及暂存源释放仍由调用者负责。

定向合成测试覆盖默认行为、精确契约扩展、原配置不变、未知/不完整/未绑定路径、外部数据拒绝、流长度、生产器错误、模式和缓冲区限制、取消、pack JSON 不匹配及有界耗尽。已有生产配置测试仍通过。不声称真实浏览器、游戏、设备或端到端安装证明。

## 可选生产器编排

`prepareBrowserPackager({legacyAstc: true})` 在公开引导阶段预加载封闭的
`legacy-astc` 组；非可编辑 API 调用方的默认 false 行为不变。浏览器界面使用
`editableOptions: true`，无论开关状态都预加载该组，仅在启用 ASTC 的生成开始时
初始化工作线程。两条路径均从已验证公开字节初始化，然后一次性生产器使用认证
提取能力，完成后才构造资源适配器。只有最终 `{pack,records}` 元数据进入资源生成，外部包字节
和索引 TSV 绝不进入 IPA。

实现限制：每个编码或解码记录 256 MiB、暂存包 8 GiB、每批编码 4096 个块。
这些是实现限制，不是原生兼容性证明。超大记录失败而非被跳过；原始错误原因保留
大小或配额诊断。

基于 File 的补充包在资源导出之后、打开 IPA 输出之前，写入已授权输入目录中的
全新自有子目录。`legacyPack` 结果与 `resources` 和 IPA 提交状态分开报告。
进度使用 `stage: "legacy-pack"` 及导出器状态、字节和文件计数。导出失败阻止 IPA
完成。后续失败时，先前完成的目录可能保留并单独报告。生产器租约在作业清理后关闭；
清理失败保持可观察且不替换主要原因。合成测试不构成真实浏览器、游戏或原生兼容性证明。
