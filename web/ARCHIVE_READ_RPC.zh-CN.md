# 有界归档读取 RPC

[English](ARCHIVE_READ_RPC.md)

`archive-read-rpc.mjs` 独占一对专用 MessagePort。不创建工作线程、不获取代码、不认证清单行，也不接受路径或键作为权限。可信父线程打开原始认证记录令牌，仅注册其不可变来源闭包。

## API

- `createArchiveReadRpcHost(port, {signal,maxPending=1})`：`register(source)` 返回冻结的 `{id,size}`，包含随机 UUID 能力与规范十进制大小。来源为 `{size:bigint,readAt(bigint,count,{signal})}`。注册时快照大小并绑定原始方法。最多 32,768 个来源，大小最多 uint64。来源必须保持不可变，并自行限制所选记录范围及有效会话。
- `createArchiveReadRpcClient(port, {signal,maxPending=1,timeoutMs=30000})`：`open(descriptor)` 返回冻结的 `{size:bigint,readAt(bigint,count,{signal})}`。拒绝重复打开描述符。描述符及记录元数据必须通过可信父线程初始化传入，而非用户输入。
- 两端均提供 `close()`。宿主的 `revoke(id)` 关闭整个专用作业通道，而非仅一个来源。取消任何读取也会关闭通道并拒绝所有在途读取。不相关作业应使用独立端口对。

每次读取最多 65,536 字节。线上偏移使用规范无符号十进制字符串，不使用有精度损失的 Number；请求 ID 为严格递增且不复用的安全整数。两端并发默认 1，可配置为最多 16。超额本地调用立即拒绝 `ARCHIVE_RPC_BUSY`，调用方必须等待读取，不应堆积队列。宿主独立执行并发限制。客户端期限为 1–120,000 毫秒。

响应包含新建且大小准确的可转移 ArrayBuffer。拒绝共享、可变大小缓冲与短读。不分离来源所有的缓冲。畸形、未知能力、过期、重复、非请求响应、超限及额外字段消息均关闭通道。关闭端点会释放监听器与定时器、清空能力映射并拒绝在途客户端读取。来源收到宿主 AbortSignal；若忽略取消，则禁止发布迟到结果，而不宣称已强制取消。意外静默端口丢失由客户端请求期限约束。外部错误替换为固定安全代码，不包含来源文件名。

## 工作线程与存储所有权

工作线程核心可将客户端 readAt 来源直接交给 `stageArchiveRecord`；可信记录元数据单独传入。RPC 不转移 WeakMap 来源证明，也不允许调用方重新构造认证令牌。只有可信父线程注册才能建立来源绑定。

父线程必须拥有独立 OPFS 作业目录，并在将目录访问权交给工作线程之前保留清理句柄。线程终止后撤销此通道，仅清理该自有子目录，并保留可观察的待完成或失败清理。此模块有意不实现线程生命周期、硬终止、存储删除、编码器预加载或运行时清单。

合成测试覆盖超过 Number 精度的准确偏移、有界背压、来源错误、共享缓冲、取消与撤销及期限、重放与畸形消息、监听器释放，以及真实 Node MessageChannel 往返。不宣称验证了浏览器线程、OPFS、私有归档或游戏数据。
