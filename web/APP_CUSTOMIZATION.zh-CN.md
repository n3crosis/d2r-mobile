# 本地应用标识定制

简体中文 | [English](APP_CUSTOMIZATION.md)

可选高级字段先修改生成的**未签名 IPA**，随后既有可选签名器处理修改后的归档。
空白字段保留固定外壳原值；全部为空时直接返回原始 Blob，不解析或重写归档。
这些选项不更新游戏、可执行文件、外壳或最低系统版本。

- 显示名称：1–80 个 Unicode 字符，无控制字符或首尾空白。修改
  `CFBundleDisplayName`、`CFBundleName` 及已有的 `CFBundleSpokenName`。
  不更改应用目录和可执行文件名。
- 包标识：最多 255 个 ASCII 字母、数字、连字符及点；至少两个非空分段。
  不支持通配符。新标识可能创建新的应用容器，不会迁移存档或设置。
- 发布版本：三个无多余前导零的十进制分段，例如 `2.1.0`，总长最多 32 字符。
  仅修改 `CFBundleShortVersionString`。
- 构建版本：独立可选的 `CFBundleVersion`，一至三个分段；首段 1–9999，
  后续各段 0–99。不支持开发后缀或前导零。更改发布版本不会自动改构建版本。
  未修改的外壳原版本不受新输入格式规则影响。
- 图标：本地 PNG，最多 4 MiB，正方形边长 256–1024，非交错 8 位 RGB/RGBA。
  RGBA 每个像素必须完全不透明。不支持 APNG、调色板、透明图、SVG、JPEG，
  拒绝校验和错误及解压超限。丢弃输入元数据，不进行色彩配置转换。

## 图标范围

有界本地解码器生成 14 个普通 RGB PNG，覆盖常见 iPhone/iPad 尺寸。
两个 `CFBundleIcons` 主图标字典引用新文件，并移除旧目录及备用图标声明。
原始 PNG 和 **Assets.car 字节保持不变**，不会调用资源目录编译器、Canvas、
远程图片服务或浏览器图片解码器。

这只是**独立 PNG 定制**，不是重新编译资产目录。未验证现代 iOS 的目录变体、
着色/深色/分层外观及真实主屏幕显示，不能宣称所有图标位置或 App Store 分发都适用。

## 完整性、签名和恢复

根二进制及严格 UTF-8 XML plist 读写均限 1 MiB、32 层和 4,096 节点，
并限制二进制重复引用展开总量。重复键、循环、实体声明及不支持的表示形式均拒绝。
发现根本地化 `InfoPlist.strings` 时拒绝名称/发布版本修改，避免某些语言仍显示旧值。

定制发生在固定外壳、组装和着色器验证之后。只有根 Info.plist 和新增图标变化。
游戏资源、可执行文件、Guest plist、着色器凭据及 Assets.car 通过不可变 Blob 切片保留。
ZIP 校验的资源读取块最多 4 MiB，序列化载荷切片为 64 KiB；中央目录最多 8 MiB，
完整 IPA 最多 512 MiB。不新增整包 ArrayBuffer 或整棵资源树复制。
重新打包需要额外 CRC 扫描，可能耗时。

签名器读取定制后实际根包标识，保持既有证书/描述文件/团队/application-ID 校验、
具体授权限制、固定路径及空原生编辑参数。原包标识的描述文件不能授权其他标识，
除非其受支持的通配授权匹配。不能指定任意授权或改写描述文件。
签名失败保留定制后的未签名 IPA。

组装后的定制失败仅保留**原始、未定制的未签名 IPA**，以明确恢复标签提供，
不自动签名也不宣称定制成功。本功能不上传或持久保存私有输入。

## 验证边界

定向 Node 测试仅使用自造 XML/二进制 plist、惰性 ZIP 资源及 PNG；由 Python
标准 plist 解析器独立验证类型往返。覆盖全部 PNG 过滤器、透明度/尺寸/解压边界、
默认字节一致、不可变载荷、引用展开、取消、不安全归档及签名源码保护。
另只读核对了两份固定公开外壳 plist 的发布摘要，均可解析/序列化。
未构建原生/WASM，未使用真实凭据，未运行签名、浏览器、模拟器、GPU 或设备测试。

Apple 官方格式依据及链接见英文版本；本功能有意只接受较窄的结构化输入子集。
