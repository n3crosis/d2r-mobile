# 已登记的游戏与外壳兼容性

English: [PROGRAM_COMPATIBILITY.md](PROGRAM_COMPATIBILITY.md)

浏览器目前只登记一组精确的游戏程序：Switch D2R 3.3.94012。`main` 和 `sdk`
的完整文件 SHA-256 来自原生提取校验。两份认证宿主配置分别为面向 iOS 26 和
iOS 18 的 v1.0.18。此次修改没有增加其他游戏版本、第三份外壳，也没有证明
设备或游戏运行兼容性。

## 现有扩展点

`program-release-catalog.mjs` 是仓库控制的版本目录。程序适配器先同步复制两个
具有来源证明的输入缓冲区，再计算摘要，使用完整的有序模块摘要组合选择版本，
不再假定唯一版本。已知 `main` 搭配未知或不匹配的 `sdk` 会以模块版本不匹配拒绝；
全部未知的输入会以不支持的版本拒绝。部分匹配绝不授权重写。

每个外壳具有不可变的 `programReleaseIds` 显式白名单。已登记但不属于该外壳的
程序会在创建工作线程之前被拒绝。配置标识和只读界面兼容性摘要从目录生成。
工作线程独立查询同一仓库版本，再检查模块摘要、构建 ID 和固定的重写器源码。
源码摘要和原生的版本专用重写规则均未改变。

这些是仓库扩展点，不是运行时注册接口。调用方不能用替代目录、版本字符串、
自定义外壳清单、源码摘要或偏移覆盖生产验证。合成测试目录路线仍与密封应用
客户端隔离。`diagnoseRegisteredProgramDigests` 只比较摘要声明，不认证来源。
只有适配器独占快照的实测摘要和工作线程独立检查的字节能够进入重写。

`program-compatibility.mjs` 提供已登记清单与固定、保护隐私的诊断代码。摘要明确
表示不支持任意游戏版本、自定义外壳导入、浏览器原生源码重建，也没有真实游戏
验证。诊断不显示私有文件名、输入摘要、原始异常或密钥。

## 增加真正的游戏版本

仅增加一行目录并不足够。原生源码仍绑定 3.3.94012：`patch_nso.py` 的规则地址和
构建 ID 检查，以及宿主的函数、数据地址和表布局都是版本专用的。启用新版本前
需要满足以下全部条件：

1. 独立确定完整 `main`、`sdk` 摘要、精确模块顺序、标题身份及可获得的构建 ID。
   不能以版本标签或复制的文件名代替身份。
2. 针对这些精确字节审查原生重写规则和宿主 ABI，并提供匹配的浏览器生成规则、
   源码固定值和可复现的合成差分证据。原生源码改变后需要重新构建密封运行时；
   此次补丁不运行也不提供该构建。
3. 与所选宿主匹配的着色器目录、源码及编译器契约、生成资源来源和派生表维度。
4. 独立检查并认证兼容外壳，在其显式程序白名单中登记新版本，再完成本地私有
   输入和设备验收。仓库登记本身不是运行证据。

## 增加真正的外壳或支持用户提供的外壳

目前明确不启用任意外壳导入。结构正确的 ZIP、看似合理的 Mach-O 目标或用户自己
提供的摘要，无法确定原生 ABI 兼容性，也不能独立认证其内容。新增外壳需要：

- 不含游戏内容的公开归档，独立确定的发布者和源码来源、归档大小及摘要、安全且
  完整的条目清单与逐文件摘要，以及实测 plist、Mach-O 部署目标和可执行文件身份。
- 真实构建、源码及工具链设置和依赖闭包，而不仅是发布标签。不能用自述元数据
  掩盖已记录的源码与发布外壳之间的来源缺口。
- 独立检查宿主容量、Guest、fixup、gate ABI、产品和链、完整着色器摘要、编译器
  版本及必需资源清单。若保留无 DLC 派生，还需要唯一符号、区段、偏移、原始字节
  和独立固定的完整派生可执行文件摘要。
- 审查后的 `shell-profiles.mjs` 记录、显式程序绑定、独立的
  `runtime-build/package.mjs` 下载及构建固定值和证据路径。继续交叉核对所有内容；
  新增配置不能绕过归档完整性校验。
- 合成拒绝和差分检查，以及单独的私有输入和设备验收。

外壳不能定义自己的信任根。未来若提供本地外壳路线，需要先建立独立受信任的
登记与来源证明流程。

## 源码重建是另一项工作

在 Chrome 中重编译任意 iOS 宿主源码，需要真正兼容的编译器、链接器、Apple SDK
及框架接口、Objective-C 和原生依赖、资源工具，以及可复现的构建和来源证明流水线。
导入二进制、修改部署字段或禁用摘要并不是该工具链。此次修改未运行原生、编译器、
Xcode、模拟器、GPU 或浏览器构建。

专项 Node 测试覆盖完整组合匹配、畸形及部分匹配拒绝、不可变目录和配置绑定、
固定代码隐私、工作线程创建前拒绝、独立构建 ID 检查、工作线程拒绝，以及原有
缓冲区清理。合成测试中替换摘要的地方均明确标注，绝不作为真实游戏证据。
