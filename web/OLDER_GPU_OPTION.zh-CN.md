# 可选的较旧 GPU 导出

[English](OLDER_GPU_OPTION.md)

**较旧 GPU 选项（实验性）**默认关闭，独立于 iOS 目标。使用 iOS 18 并不代表设备需要该选项。两项选择都不保证设备兼容性；没有宣称已取得真机运行结果。

请在选择输入文件夹之前选择此选项。切换会重新加载页面（网址中的 `legacyAstc=1`），以便在选择私有文件之前预加载所需的公开资源。选择文件夹后选项会锁定；如需更改，请重新加载。私有文件与密钥留在本地，转换过程不依赖网络。

启用后，生成过程还会在所选输入文件夹中单独保存 `Legacy Device Pack-<UUID>` 文件夹。其进度与完成状态独立于 IPA 显示。请将完整的 Legacy Device Pack 文件夹与游戏资源一同复制到已安装应用的“文件”文件夹。仅下载 IPA 并不足够；签名与安装仍需另行完成。

补充包完成不代表 IPA 完成。如果后续生成失败，补充包可能显示已完成，但 IPA 仍不可用。请勿使用未完成或已取消的补充包；清理后可能仍保留未完成标记。请重新加载并重试，不要通过重命名将不完整输出放入应用。不勾选时的正常流程保持不变。

界面源码检查和合成导出测试不能证明真实游戏输入、浏览器端到端流程或设备兼容性。
