# 经过验证的归档流式暂存

[English](ARCHIVE_STREAM_READER.md)

`archive-stream-reader.mjs` 添加独立的有界暂存 API。不修改 `decodeArchiveRecord`、其默认值或 16 MiB 整记录限制。不认证路径到 EKey 的关联，也不建立首个清单行语义。这些决定属于已认证提取层。

## 公共 API

`stageArchiveRecord(source, record, { root, maxDecodedBytes, maxEncodedBytes, signal, createStage })`

- 来源：`{ size: bigint, readAt(offset: bigint, count: number, {signal}) }`，整个操作期间必须指向同一个不可变归档。每次归档读取最多 65,536 字节。绝对偏移保持 BigInt。
- 记录：`{ offset: bigint, encodedSize, decodedSize, encoding, ckey, ekey }`。大小为非负安全整数。两个 32 字符十六进制键均为必填。EKey 的 40 位偏移必须等于记录偏移。调用者可信层必须建立正确归档与路径关联；解码器无法针对匿名来源认证 EKey 中的块号与档号。
- 必须显式提供编码与解码总预算，为不大于 uint32 最大值的安全整数。BLTE 可支持超过原整缓冲 API 的总大小，不修改旧 API。保留原有 4096 块与每个编码或解码块 4 MiB 上限。非 BLTE 的 n/z 保留原有单块 4 MiB 上限。
- 默认暂存实现为 `createRawFileStage`，要求调用者拥有的 OPFS 根目录。注入用于同样受所有权管理、具备 `append`、`finalize`、`dispose` 的暂存对象，不是认证机制。它接收 `{root,maxBytes:decodedSize,signal}`。不提供内存回退。
- 成功返回 `{size:number, readAt(offset:number,count:number,{signal}), dispose()}`。读取相对于解码内容，最多 1 MiB。仅完整验证成功后暴露此能力。不暴露部分输出块或未验证 File 句柄。使用完毕后释放，后续读取失败。

## 校验与资源边界

按魔数识别 BLTE，即使声明规格为 n。验证头部标志、条目数、准确头部大小、编码与解码范围及准确总数。块模式仅接受大写 N 与 Z。EKey 摘要前缀覆盖 BLTE 头部或整个非 BLTE 编码记录。每个 BLTE 块 MD5 包含模式字节。完整解码 CKey 增量计算，并在暂存最终化前必须匹配。

为保留先校验再解码的顺序，编码块先以最多 64 KiB 分片散列。最多 1 MiB 的块缓存一次并从已验证缓存解码，避免普通块重复认证读取负载。较大块不保留，而从同一不可变来源重读解码。解码遍再次检查编码校验和，并要求完整 MD5 与第一遍一致，包括 EKey 仅保存摘要前缀的非 BLTE 记录。第二遍字节变化时，即使解码内容相同，也不能发布。算法一次仅保留一个编码缓存；头部探测与表读取仍单独进行。可变来源违反来源契约；重读不能代替提取认证。

原始输出以最多 64 KiB 块追加。Zlib 输入使用 1 KiB 顺序背压分片，同时排出输出，按声明的解码块大小检查，并复制为最多 64 KiB 的独占暂存块。不创建解码记录大小的缓冲区。BLTE 元数据最多占用 98,316 字节头部与有界块描述，另有最多一个 1 MiB 编码块缓存。DecompressionStream 内部缓冲、引擎返回块、暂存实现及延迟垃圾回收会增加开销：这些缓冲上限不是浏览器总 RSS 的硬保证。应在有界工作线程执行解码，而非 UI 线程。

## 失败与取消

AbortSignal 传入读取与自有暂存。可以取消对待完成宿主 I/O 的等待，但解码器不宣称能够强制取消忽略信号的来源。解压生产者与消费者一起停止。所有失败路径均释放已获取暂存；迟到的暂存获取仍有所有者，到达后会被释放。外部读取、写入或编码器错误在对外报告前净化。

清理最多等待一秒。仍在进行或失败时，错误暴露 `cleanup` Promise 与已净化 `cause`。调用者必须保留并观察该 Promise，不得声称清理已完成。独立的迟到获取或释放失败会以原始内部错误拒绝该 Promise，包括 AggregateError；这些诊断细节不适合直接面向用户显示。已经报告的获取主错误以及取消后的正常迟到 AbortError 不重复报告为清理失败。在 CKey 校验、准确输出大小与成功最终化之前，不发布输出或成功能力。对于不返回的原生浏览器操作，调用者仍应设置外层工作线程期限。

## 合成证据

专项测试将 n/z/BLTE 字节与现有解码器对比，保留超过 4 GiB 的准确偏移，测试空 n/z 与 BLTE 魔数优先，拒绝校验和、头部、模式、边界与短读损坏，限制解码输出大小，并验证取消及迟到或待完成清理。17 MiB 合成 BLTE 记录通过计数接收器成功暂存，不保留解码内容；原整缓冲解码器仍拒绝该大小。回归测试覆盖延迟获取拒绝、清理期限后的迟到释放失败，以及较大原始或压缩输入在第二遍变化（包括解码内容不变）的情况。仅使用生成字节，不涉及游戏文件或密钥。原有 archive-reader 测试未修改。浏览器 OPFS 端到端证据仍需补充，注入测试接收器不代表浏览器存储验证。
