# 有界原始文件暂存

[English](RAW_FILE_STAGE_SCOPE.md)

## 范围

`raw-file-stage.mjs` 是独立的本地 OPFS 暂存原语，用于后续增量生成的原始文件。尚未接入 ASTC 补充包、界面或生产打包流程。测试仅使用合成内存文件系统替身，不是实际浏览器、设备、配额或崩溃恢复证明。

## 调用契约

- `await createRawFileStage({ root, maxBytes, signal, randomUUID })`：调用者提供 OPFS 根目录；`maxBytes` 是必填的非负安全整数，包含最终文件的全部字节。默认 UUID 来自 `crypto.randomUUID()`；注入仅用于可信宿主或测试。
- `append(Uint8Array)`：在当前末尾追加；每次最多 1 MiB，不能超过总预算。
- `backpatch(offset, Uint8Array)`：只能覆盖已有字节；偏移必须为非负安全整数，不扩展文件、不产生稀疏间隙。每次最多 1 MiB。
- `finalize()`：一次性关闭写入流，随后获取并校验文件快照；返回 `{ file, size, readAt(offset, length) }`。关闭后拒绝写入和再次 finalize。
- `readAt`：可重复读取已完成文件的范围，每次最多 1 MiB；偏移、长度必须是非负安全整数且完全位于文件内，返回 `Uint8Array`。
- `dispose()`：立即禁止后续操作，等待正在进行的文件系统调用返回，然后中止剩余写入流并删除自有子目录。可重复调用；清理失败可以重试。

如果提供 `signal`，必须为真实的 `AbortSignal`，不能是模拟接口对象。写入拒绝共享或可调整大小的底层缓冲区；即使传入视图很小，底层 `ArrayBuffer` 大于 1 MiB 也会被拒绝，以限制异步写入期间保留的输入内存。

## 所有权和错误

临时目录名为 `d2rm-raw-<UUID>`，目录内固定文件为 `data.bin`。先检查目录不存在，再创建；已有条目或错误类型不会被复用或删除。OPFS 没有独占创建原语；同源脚本必须可信。只能删除本次成功创建的子目录，不扫描目录、不清理未知文件、不写入用户源文件夹。

操作必须串行等待；并发调用会被拒绝。调用者在写入完成前不得修改传入的字节。验证或文件系统操作失败会终止暂存并尝试清理；关闭、配额、读取和写入错误不会被当作成功。清理同时失败时，`AggregateError` 保留原始原因及清理错误。取消会触发清理；调用者仍应在 `finally` 中 `await dispose()`，以观察或重试失败的清理。不能取消已经进入浏览器的原生调用，清理需等待其返回。

返回的 `File` 是浏览器文件快照，不会被完整读取到 JavaScript 内存；`readAt` 只读取有界切片。浏览器原生 `File` 无法被此模块撤销：释放后包装器拒绝读取，但调用者自己保留的 `File` 仍受浏览器语义约束，不能保证立即不可读或立即释放存储。调用者须释放所有引用。浏览器崩溃可能遗留目录，模块不自动清扫。没有配额预留保证、内存回退、上传或网络行为。
