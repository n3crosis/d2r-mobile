# 着色器输出内存边界

[English](SHADER_MEMORY_BOUNDS.md)

生产着色器输出保留既有 512 MiB 上限。基础和 fetch 源码字节只计一次。
紧凑回放 JSON 预留临时预算；完整源码摘要证明通过后，以添加 chain 后实际格式化的
JSON 字节替换该预留。最终 c1 索引也计入预算。超限输出在保留之前失败。
输出格式、源码摘要检查和 noMetal/设备端编译设计均保持不变。

每次输出回放产生拥有独立缓冲区的副本，底层缓冲区最多 64 KiB，且每块之前检查
取消及释放状态。拼接字节保持完全一致。这只限制单次回放副本，不限制所有保留输出。

进入嵌入着色器时擦除并释放旧物理包，重置缓存身份。主镜像一直保留到所有嵌入记录
完全处理结束，即使这些记录不连续；最后一次完成后擦除并释放。之后再次访问物理包
会重新加载，不复用过期字节。失败及最终清理擦除剩余来源。每个来源的既有 256 MiB
限制不变，没有提高任何上限。

## 有界包记录索引

生产路径使用 `catalog.createOwnedPackSource(name, packBytes)`，只返回
`prepare(key, flags)` 和 `dispose()`。它转移完整的普通 ArrayBuffer 底层存储，
分离调用方的所有别名，不复制整个包。共享、可调整大小的缓冲区及子视图会被拒绝，
没有复制回退。来源切换及最终清理会释放所有者；准备失败会终止所有者并擦除包与索引。
取消或释放后才返回的结果，其独立代码缓冲区也会被擦除。

私有 Uint32 偏移表受固定目录中该包最高选中索引加二的限制：同时保留的一个包最多
占用 **17,284 字节**。偏移按需扫描填充，保留原生 `BTCDBTCD` 非重叠匹配、
EOF 边界以及重复和乱序请求语义。公开的 `catalog.prepare(key, {packBytes})` 行为，
以及每条记录的控制段摘要、阶段、c1 和大小检查都保持不变。

固定目录选择 149 个包中的 6,923 条记录，另有四条嵌入记录。反复从包头扫描至少需要
7,843,265 次成功标记匹配。一次调用实际 API 的 Node 合成运行，让每个包结束于其最高
选中记录，原始准备路径共完成 **7,850,039** 次完整标记匹配，拥有所有权的索引路径为
**10,058** 次。仅为执行记录选择而模拟了合成控制段摘要，没有运行真实翻译。
这些只是操作次数，不是浏览器耗时、RAM 测量或真实游戏证明。

聚焦合成测试验证预算、分块底层大小、取消及缓存生命周期，不测量浏览器 RAM 节省，
也不构成真实游戏验证。
