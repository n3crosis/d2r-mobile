# 资源导出选项

[English](RESOURCE_EXPORT_OPTIONS.md)

默认导出直接在输入目录内创建简单的 `data` 文件夹。已有 `data` 会与当前输入完整比对，只有匹配时才只读复用。此验证只检查本地文件，不检查设备文件。无法验证时不更改其中的任何内容；请将其移到其他位置，或在适用时明确选择跳过。旧 UUID 外层目录不会自动迁移：你可以自行将里面的 `data` 移至输入目录，随后仍需通过验证。独立补充包使用 `Legacy Device Pack`，重名时依次使用 `Legacy Device Pack-2`、`-3`，不会覆盖旧输出。

默认仍会完整导出游戏资源。选择输入文件夹后，只有在设备上已存在相同游戏、更新和 DLC 的资源时，才可主动勾选**跳过资源导出（设备上已有）**。浏览器不会检查或验证设备上的已有文件。选择其他文件夹或更改所选安装包，会将此选项重置为完整导出。

跳过仅省略原始游戏资源文件夹的导出。输入认证、提取和 IPA 内生成资源仍会执行。启用较旧 GPU 选项时，仍会单独导出 Legacy Device Pack，并需要将其复制到设备。仍使用现有输入文件夹作为导出目标，不新增文件夹选择器。

结果会明确显示资源导出已跳过，而不是已完成或已验证。该跳过状态独立于 IPA 的成功或失败。

空间提示估计的是浏览器管理的暂存空间，而不是导出目标磁盘的剩余空间。它不会预留空间，也不保证生成所需空间足够。估计不可用、无效或超时不会阻止继续操作。生产大小上限或输入安装包大小不会被当作已知暂存需求。获取估计时不会发送私有文件或密钥。

源码约束和合成测试不能证明浏览器、真实游戏输入或设备运行成功。
