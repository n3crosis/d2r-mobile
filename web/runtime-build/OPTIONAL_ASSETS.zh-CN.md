# 可选公开编解码器资产

运行时组装包含完整可选生产器闭包，但默认准备既不下载其编解码器，也不创建其工作线程。
这个内部准备选项不开放界面功能，也不证明浏览器、设备或完整游戏一致性。

## 封闭清单契约

`web/runtime-asset-groups.mjs` 定义精确的 `legacy-astc` 生产器组：

- 一个封闭且已打包的生产器工作线程。
- Arm ASTC 工厂 JS、WASM、许可证、源码提交及编译器凭据。
- 独立流式 SHA-256 WASM、两份 mbedTLS 许可证及构建报告。

组内每个资产均携带 `optionalGroup: "legacy-astc"`。可选组只能完整存在或完全缺席；
未知组、未知路径、缺失标签及不完整组均验证失败。通用依赖与外壳归档不得标为可选。
已有 `toolchain/asset-runtime-js/dist/png-codec.wasm` 保持通用，必须复用而非复制到可选组。
SHA 构建报告已包含源码固定记录；ASTC 现有源码及编译器凭据完整保留。

## 传输与选择

组装通过 `createRuntimeTransport(contents, { assets })` 传入完整且已标记的逻辑清单。
当可选许可证的摘要及字节数与已有通用资产完全相同时，以通用归属为准。
其余仅可选组需要的字节单独打包。物理载荷不能混合不同有效归属，
即使当前选择将省略该包也必须验证。无需新增传输结构字段。
没有可选资产时，传输格式与字节保持不变。

`validateRuntimeProfileSelection(manifest, profileId, { optionalGroups: [] })`
默认省略全部可选组，同时保留现有精确外壳选择及完整性检查。
显式选择 `["legacy-astc"]` 时必须存在完整组。打包清单及旧式未打包清单均受支持；
下载进度只统计所选物理字节。

## 生产器准备及生命周期

受信任调用方通过 `prepareSealedRuntime({ ..., optionalGroups: ["legacy-astc"] })` 选择启用。
在接受私有输入之前，引导固定选项快照、验证全部所选公开资产，
用转移的 ASTC JS/WASM、SHA WASM 及已有 PNG WASM 初始化生产器，
并完成所有请求工作线程的启动检查。ASTC 工厂获得已验证的 `wasmBinary`、
严格匹配的 `locateFile` Blob URL 及显式字节实例化钩子。生产器禁止网络回退。

之后 `session.createAstcProducerClient()` 才能且只能获取一次预备生产器。
未预备、已获取或已关闭的会话直接失败，不联网。
客户端提供 `produce(extracted, selection, options)` 和 `close()`。
打包及最终输出提交完成前必须保留 File 租约。应等待客户端和会话清理；
`session.close()` 立即撤销会话、终止工作线程，同时返回可观察清理结果的 Promise。

原始生产器客户端及精确相对导入闭包保持为通用引导 JavaScript。
它们不包含编解码器二进制，也不启动生产器。不得将其与认证模块独立打包，
否则会复制私有来源注册表。只有隔离工作线程被打包到可选组。
组装在纳入完整组之前验证编译器、源码凭据及 SHA 本地源码哈希。

专项测试使用合成记录、字节及隔离引导模拟，验证清单闭包、默认下载隔离、去重、传输完整性、
启动顺序、清理及不变的外壳选择。真实 Bun 打包检查生产器工作线程的静态导入闭合。
这些检查不证明真实编译器输出、浏览器执行或设备一致性。

## 本地源码构建大小快照

以下数据是在本次集成期间于 2026-10-20 使用 Bun 1.4.3 本地测得，不是已部署载荷：
可选生产器工作线程压缩代码为 88,216 字节，gzip 级别 9 后为 30,767 字节，
没有剩余字面量导入。其动态工厂导入是前述已验证初始化 Blob。

两次隔离前端构建的唯一区别，是将生产器客户端替换为只供测量的占位实现。
真实客户端为通用前端增加 15,880 字节压缩代码及 5,318 字节 gzip 数据。
两次构建均生成一个 JavaScript 包；ASTC/WASM 编解码器不在其中。
这些数据衡量共享客户端及所有权逻辑，不代表可选二进制传输大小或已部署发行版总量。
另以 Bun 导入扫描器审查完整原始 `clients.mjs` 依赖图，全部 30 个精确源码或 JSON
路径都已包含在打包白名单中。
