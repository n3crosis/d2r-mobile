# 可选公开编解码器资产

此改动仅为清单及传输基础。运行时组装尚未包含可选编解码器，
`prepareSealedRuntime` 尚未提供选择开关，也未启用生产器或界面功能。

## 封闭清单契约

`web/runtime-asset-groups.mjs` 定义精确的 `legacy-astc` 编解码器组：

- Arm ASTC 工厂 JS、WASM、许可证、源码提交及编译器凭据。
- 独立流式 SHA-256 WASM、两份 mbedTLS 许可证及构建报告。

组内每个资产均携带 `optionalGroup: "legacy-astc"`。可选组只能完整存在或完全缺席；
未知组、未知路径、缺失标签及不完整组均验证失败。通用依赖与外壳归档不得标为可选。
已有 `toolchain/asset-runtime-js/dist/png-codec.wasm` 保持通用，必须复用而非复制到可选组。
SHA 构建报告已包含源码固定记录；ASTC 现有源码及编译器凭据完整保留。

## 传输与选择

未来组装通过 `createRuntimeTransport(contents, { assets })` 传入完整且已标记的逻辑清单。
当可选许可证的摘要及字节数与已有通用资产完全相同时，以通用归属为准。
其余仅可选组需要的字节单独打包。物理载荷不能混合不同有效归属，
即使当前选择将省略该包也必须验证。无需新增传输结构字段。
没有可选资产时，传输格式与字节保持不变。

`validateRuntimeProfileSelection(manifest, profileId, { optionalGroups: [] })`
默认省略全部可选组，同时保留现有精确外壳选择及完整性检查。
显式选择 `["legacy-astc"]` 时必须存在完整组。打包清单及旧式未打包清单均受支持；
下载进度只统计所选物理字节。

## 生产器集成门槛

专用生产器存在之前，不得将编解码器资产加入组装或开放功能。
其封闭工作线程入口及任何新增凭据必须明确加入注册表和测试。
在接受私有输入之前，引导必须选择可选组、验证全部公开资产，
用已验证的 ASTC JS/WASM、SHA WASM 及已有 PNG WASM 初始化生产器，
并完成现有工作线程启动检查。之后不得通过网络加载依赖。
若稍后请求未预备的生产器，必须失败，不能按需联网获取资产。

专项测试只使用合成记录及字节，验证清单闭包、默认下载隔离、去重、传输完整性及不变的
外壳选择，不代表编译器、生产器、浏览器或设备一致性验证。
