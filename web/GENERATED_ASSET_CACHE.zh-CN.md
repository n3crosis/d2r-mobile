# 重复生成时的图像缓存

生产资源适配器可通过可选本地输出缓存复用原生图像、HUD 和地图目标生成器的
编码结果，包括 HUD 字形与地图标签。它不缓存原始字体、源纹理、解码像素、
提取会话、密钥或签名凭据。

每次仍打开当前已认证或本地输入能力，读取并验证生成器需要的当前来源。缓存键
包含完整工作线程输入负载的 SHA-256、操作选项、已验证运行时清单摘要、外壳配置
及图像/覆盖配方版本。负载包含源图像、字体、文字、布局及前序生成结果。仅游戏
版本或文件名相同不足以命中缓存；缺少运行时身份时不启用资源复用。

缓存边界位于源解码之后、渲染之前。命中只跳过相应生成器的工作线程操作，不会
跳过输入验证、解码、整个资源阶段或资源导出。纹理编码、派生表、CASC 覆盖与
可选 ASTC 包仍重新生成。目前不作重复运行耗时承诺。

`asset-output-cache.mjs` 分别存储编码输出，并最后提交有界结果索引。单文件最多
16 MiB；原生图像/HUD 每组缓存最多 64 MiB，地图目标每组最多 16 MiB。这些是
缓存预算，不是实测大小或浏览器进程内存保证。读写串行，不额外组合整个输出归档
或 base64 副本，仅保留单个生成器本来需要的结果集合。

`local-output-cache.mjs` 的独立同源账本验证索引和文件快照，不能仅信任文件夹中的
回执。缓存与新生成结果经过相同的输出检查。缺失、损坏、超限或验证不通过的缓存
回退到正常计算。新结果通过检查后才写入缓存，部分写入不会发布完整索引。取消
仍中止任务并擦除已持有的返回字节。

忽略缓存选项绕过本地缓存读取；成功的新生成结果仍可更新缓存。公开运行时下载
缓存独立存在。删除所选文件夹内的 `.d2r-cache` 会使下次重新生成计算结果，不得
删除原始输入、`D2R-resources-*`、`Legacy Device Pack-*` 或 IPA 输出。现有资源
完成标记缺少绑定来源的逐文件摘要，因此本功能不自动复用或认证这些目录，也不
证明手机上已安装哪些资源。

聚焦合成测试覆盖命中、来源/配置失效、拒绝或损坏存储、输出复验、取消、部分
写入及预算限制。未使用游戏输入、编译器或浏览器，不证明真机性能或转换兼容性。
