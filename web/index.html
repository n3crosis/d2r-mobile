The intended finished workflow

  1. Select your own game folder and a compatible shell.
  2. Validate versions and generate the missing program, art, data and shaders locally.
  3. Save an IPA to disk, then sign and install it with your chosen tool.
  4. Copy the large resource archives to the installed app separately.

No account credentials, signing keys or uploads. The current preview explicitly blocks network connections. Chromium on desktop Windows/macOS is the initial target; API availability is checked rather than assumed.
